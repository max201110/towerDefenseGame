# Tower Defense Game

A web-based tower defense game built with Flask backend and HTML/CSS/JS frontend.

## Features
- Classic tower defense gameplay
- Responsive web interface
- Flask backend support

## Quick Start

```bash
git clone https://github.com/max201110/towerDefenseGame.git
cd towerDefenseGame
pip install -r requirements.txt
python app.py
```

## Tech Stack
- **Backend**: Python / Flask
- **Frontend**: HTML / CSS / JavaScript
